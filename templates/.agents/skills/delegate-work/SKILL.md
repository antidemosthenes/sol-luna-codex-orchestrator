# Delegate Work

Apply the active project's routing table when scoping the work. For a routine inspection or bounded edit, select `luna-worker`. Under Astra, select `sol-escalation` directly for a harder independent investigation. A Sol parent handles that harder work itself.

Give the worker one deliverable, its scope, the files or context it needs, and an acceptance check. Specify read-only access for a review. Give parallel writers distinct files and tell them to preserve concurrent changes. A worker with a fresh context needs a self-contained brief.

Launch the selected worker using the controls described in the project's AGENTS.md. While it runs, do the independent parent work. Collect its result before final acceptance and check the evidence or diff. If the result is insufficient, first check whether the brief was clear and the scope manageable.

Use [the work-package reference](references/work-package.md) for a handoff that needs more structure.
